# Наш банк — стенд интернет-банка

Учебное приложение интернет-банка для тестового задания QA-инженерам.
Приложение рабочее: им можно пользоваться как обычный клиент, но в нём
сознательно оставлены дефекты. Задача кандидата — найти их, доказать и
оформить либо покрыть автотестами.

Стенд развёрнут и доступен: **https://fulcrum81.github.io/alfa-task/**

- [docs/ASSIGNMENT.md](docs/ASSIGNMENT.md) — условия задания, требования,
  формат сдачи и критерии оценки
- [docs/openapi.yaml](docs/openapi.yaml) — контракт API: требуемое
  поведение сервиса

## Как устроен стенд

Отдельного сервера и базы данных нет — стенд полностью статический, его
можно раздавать с любого хостинга статики.

- **Frontend:** Vite + React 18 + TypeScript + React Router.
- **«Backend»:** MSW (Mock Service Worker). Запросы к `/api/...`
  перехватываются service worker'ом и обрабатываются кодом в
  `src/mocks/handlers.ts`, который исполняется в контексте страницы.
- **Состояние:** `localStorage`, сидируется детерминированным PRNG —
  у каждого своя изолированная копия данных.

Что из этого важно на практике:

1. **Запросы видно в DevTools.** Network показывает настоящие запросы к
   `/api/...` со статусами, заголовками и телом ответа. Пометка
   `(from service worker)` — нормальное поведение стенда.
2. **Внешние клиенты API не видят.** Postman, curl и REST Assured не
   смогут обратиться к API: service worker перехватывает только запросы
   внутри страницы. Проверять API нужно через DevTools или через `fetch`
   внутри браузера.
3. **В Playwright нельзя блокировать service worker.** Опция
   `serviceWorkers: 'block'` уничтожит API целиком.

| `petrova` | `qwerty123` | клиент |
| `admin` | `admin123` | сотрудник |

Вход выполняется по логину и паролю, без второго фактора. Все суммы — в
белорусских рублях (`Br`).

## Управление состоянием стенда

Стенд можно вернуть в исходное состояние в любой момент:

```
POST /api/__test__/reset               # полный сброс, сессия сбрасывается
POST /api/__test__/reset?keepSession=1 # сброс данных, сессия сохраняется
GET  /api/__test__/state               # снимок состояния
```

Инъекция сбоев для проверки обработки ошибок описана в
[docs/ASSIGNMENT.md](docs/ASSIGNMENT.md), раздел 4.

Отладочная панель стенда открывается по адресу
`https://fulcrum81.github.io/alfa-task/?debug=1`: там сброс данных, балансы
счетов и число выданных токенов.

## Структура

```
src/
  api/          типы и HTTP-клиент
  auth/         контекст аутентификации
  components/   Layout, DevPanel
  lib/          форматирование
  mocks/        «серверная» часть: db.ts, seed.ts, handlers.ts, browser.ts
  pages/        Login, Dashboard, Transfer, History, Cards, Admin
public/         статика, включая mockServiceWorker.js
docs/           документы задания
```
